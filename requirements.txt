# 项目依赖清单（Requirements）
# 生成时间: 2026-08-06
# 项目根目录: /home/admin/user-app
# 说明: 本文件列出项目全部运行依赖。后端基于 Node.js + Express，前端基于 Vue 3 + Vite。
#       安装请使用 npm（Node.js v22+）。本文件同时保留 package.json 中声明的版本范围。

## 运行时环境
- Node.js >= 22
- npm >= 10
- PostgreSQL >= 16（Docker 镜像 postgres:16-alpine）
- curl（后端通过系统 curl 调用 Moonshot API，规避 TLS 指纹风控）

## 安装命令
# 后端
cd backend
npm install

# 前端
cd frontend
npm install

- 后端启动成功标志: 日志输出 "Database tables "users", "sessions", "messages" ready" 与 "Server running on http://0.0.0.0:3000"
