## 一、铁律 1（类型锚点脱敏）：采纳，且规格反超原案

DS 主张用 `reservation_abc123` 式**伪真值**而非 `<RES_ID>` 裸占位符。裁决采纳，理由比他说的多一条：

1. **测量效度**：裸占位符使注入物明显合成化，worker 可能折扣其先例价值 → Δ2 被人为压向零。伪真值保持计划的表面真实性，测到的才是"骨架迁移"本身；
2. **CopyGuard 反向增强**：伪真值取自**保留不可能命名空间**（如 `ZZZ` 前缀 + DB 非成员断言 lint），它绝不可能出现在本任务任何工具结果中——因此它一旦出现在 agent 的 args 里，就是**无歧义抄袭**，检测器零假阳性。

**修订后脱敏规格（替换 P5a.30 §5.3 占位符条款）：**
- 实体值替换为**类型匹配的伪真值**（reservation_id → `ZZZ`+6 位大写字母数字；日期 → 整体平移保关系的假日期；金额/数值 → 保量级假值）；
- 共指一致（同一实体全程同一假值）+ **关系保持**（日期先后、数值大小关系在假值间维持，否则骨架内的推理逻辑断裂）；
- lint 三检：无残余真值 ∧ JSON 可解析 ∧ **全部假值对 DB dump 断言非成员**；
- 登记设计分叉：裸占位符 vs 伪真值是注入物形态的合法变体，留作 L4 汇合时的稳健性维度。

## 二、铁律 2（谓词点火时机）：抓到真缺陷，采纳并修正作用域

**DS 抓到了 P5a.28 的真实缺陷。** 我在 Path B 写"于该次工具结果内附加条件式提醒"——工具结果意味着调用**已执行**，而锁在 items 修改执行的一刻扣上。所以 P5a.28 的 Path B 按字面实现仍然是 too-late 的，0/12 的判决对它同样成立。公开勘误。

**合法时序立法（明确三段论）：**
```
调用产生 < 调用执行 < 锁死生效
合法拦截窗口 = 执行前。两种实现：
  Path A（任务开始）：请求文本关键词谓词注入规则——最早，但有漏检率（措辞不含关键词则漏）；
  Path B'（执行前否决）：monitor 拦截 modify_pending_order_items 的执行，
    返回合成结果「INTERCEPTED：若本订单还需改地址，先地址后物品；
    若无需改地址，重新发起本调用即可通过」——调用不执行，锁不扣。
```

**Path B' 规格**：否决式（非附加式）；**每订单一次**状态位（同订单第二次 items 调用直接放行并记 span，避免死循环）；单次修改任务的误报成本 = 一次空转轮次（241 类无害点火 → 每单至多 1 轮开销，可接受）。Path A 保留为互补前置通道，不替代 B'。

**作用域修正**：锁序拦截器是 L2 资产部署，属 **e9 实验**（拦截 on/off 同轮随机），其规格进 e9 工单队列；**不进 e8 预注册**——e8 测 precedent 通道，两者不混。

## 四、沙盒门：接受形式，拒绝其成功标准

DS 要求"脱敏注入物+全新谓词沙盒测试，对照人工 S/A/U 标签，确保 S 比例显著上升，再开 e8"。裁决：

- ✅ **沙盒 shakedown 接受**——但按 P5a.21 的 mini 教义定位：**仪器试车，不是行为实验**。验收清单为机械项：脱敏库 lint 三检通过、注入物×任务矩阵可冻结、形态平衡表产出、CopyGuard 在 e7 轨迹回放中检出率符合预期（伪真值零命中真值臂历史 args）、10 任务烟跑无 crash。
- ❌ **"S 比例显著上升"拒绝作为门**。三条理由：(a) 它是过程指标，e8 的主终点（Δ2 簇 CI）就是它的上诉法院，预注册终点不许被低功效的先行指标架空；(b) 新 S/A/U 标签要再消耗一轮人工标注，为 e8 设计已替代的主观度量付费（CopyGuard + 形态平衡就是它的客观化）；(c) 10 例沙盒的 S 比例没有统计力，"显著上升"在数学上无从谈起。
- **e9 谓词可与沙盒并行烟测，但不构成 e8 的门。**
