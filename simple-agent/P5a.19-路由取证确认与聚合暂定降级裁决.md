## 一、代码级取证：三条全部接受

### F1 臂分配 = 跨 epoch 存续的 Thompson 采样（接受，后果升级）
- 事实：routing.py:34-44 读持久化后验选臂，trace_store.py:99 建表，worker.py:563 每任务 router.update() 增量更新，ε=0.1 随机探索。臂**不是每 epoch 重随机**。
- 后果 1：**跨 epoch 任务级对比默认死亡**。A-019 e4/e5 异臂是后验漂移的必然，非事故。P5a.15 §三.4 之问答案为"否"。
- 后果 2：Thompson 为**自适应分配**——epoch 内任务 t 的臂依赖前 t-1 个任务结局 → arm_value_delta 带选择偏差，降为风险监视器，禁止作因果解读。
- 抢救通道：变更点审计可比集 = **同臂 ∧ 注入内容字节一致 ∧ 过第 0 步筛查**。其中 direct 臂对天然可比（无注入=处理平稳）；precedent 臂对须内容 hash 一致。

### F2 precedent 注入 = 动态 max-similarity 选取（接受）
- 事实：worker.py:158 `list_precedents()` 动态选取，随先例库累积而变 → A-008 的 436 vs 213 tokens 为两份不同先例，非截断。
- 指令：先例库 **epoch 开始快照冻结**；`precedent_injected` span 增加 `content_hash` 字段。

### F3 路由后验键 = 请求别名（接受，限期修复）
- 事实：env_fingerprint() = MODEL_NAME = deepseek-chat（请求别名），非真实响应模型 → 后验为错误身份学习。
- 指令：epoch-6 前改为"响应模型 + system_fingerprint"复合键（与模型别名双记录工单合并实施）。e3–e5 期间服务模型是否一致不可回溯验证，记诚实局限。

- 收回 P5a.16 §六"线束噪声对两 epoch 对称作用"：该假设未检验，且与 P5a.16 §三联合因果原则自相矛盾（模拟器经由 agent 行为与 POLICY 耦合，噪声非外生）。
