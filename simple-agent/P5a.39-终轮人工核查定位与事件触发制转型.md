# P5a.39 裁决：脱敏修复验收、终轮人工核查定位与事件触发制转型

**仲裁人：Claude（任务书作者）｜日期：2026-09-30**
**输入**：opencode 修复报告（commit 4e23af1，远端 b3ff893）：两处自由文本病灶已修（词界+变体容忍替换；表达式数值统一缩放）；自查发现并修复排序 bug（先替换后缩放 → 伪值被二次缩放 PRICE_0x00x；重排为先缩放后替换，expression 仅缩一次）；机器④ 升级（价格入 DB 字典 + **文档内可解释性**判据：伪价格两位小数必须能由同文档原值 ×1.37 解释，解决稠密价格撞号 FP）。结果：distinct=443、all_pass=true、unclassified={}；达标线维持（distinct 63 / 同域 97.8%）。
**问题**：还需要人工核查吗？
**裁决：需要，最后一小轮——但这一轮之后，人工核查从"每批审计员"转型为"事件触发的回归守门员"。**

---

## 一、修复验收

- 两处病灶修法对症；**自查出排序 bug（二次缩放）是本轮最有价值的信号**——说明执行者的自查回路在收敛，残余 bug 的尺寸在三轮间单调缩小（v1=类别级缺口 → v2=自由文本覆盖 → v3=内部自洽性），这是收敛的实证形态；
- 机器④ 的"文档内可解释性"判据值得点名：它把价格检查从"黑名单匹配"升级为**可逆性不变量**（伪值 ÷1.37 必须落回同文档真值）——比字典比对强一个档次，入档为该类检查的范式。

## 二、为什么还需要最后一轮人工

三轮事故的共同点：**每一轮的逃逸者都是机器词表里没有的类**（IFOYYZ 之于残缺 lint、email/地址之于旧分类法、表达式金额之于字段级缩放）。机器④ 再强，也只能查它知道的类；**人的职责恰好是未知类**。此外还有一件机器判不了的事：替换后自由文本的**可读性**——骨架对 worker 是否还是一份"读得通的先例"（这是 Δ2 测量效度的一部分，lint 不知道什么叫通顺）。

## 三、终轮规格（约 15 分钟）

- 抽样：**自由文本重度单元 6-8 例**（含 summary/think/calculate 的计划，跨 airline/retail）；
- 只判两条：**(a) 读得通吗**（替换后的文本作为先例是否连贯、无突兀伪值堆砌）；**(b) 有无违和裸字符串**（任何不像伪真值又不像封闭词表的字符串——未知类的探测器）；
- ②③④①⑤ 全部机检已过，不再人工复核。

## 四、转型立法：人工核查事件触发制

本轮通过后即刻生效：

1. 脱敏仪器的回归测试集 = 累计审计档案（旧 10 案 + v2 14 案 + 本终轮案例），每次重生成必过机器④ + 回归集；
2. 人工核查**不再是批次门**，改为事件触发：分类法变更 / 生成器逻辑变更 / 新工具或新字段类型入库 / DB schema 变更 → 触发一轮抽检；无事件不抽检；
3. 法理：与 P5a.24 的衰减管理同构——有效性是状态，复验靠触发器不靠日历；人工判断力是稀缺资源，花在机器的盲区上，不花在机器已覆盖的确认上。

## 五、G 门状态

修复验收 ✅；终轮人工（本节三）通过后：G 门开 → E 门矩阵冻结审查（同域 97.8%、distinct 63 已预告达标，届时核矩阵原件）→ e8 运行令。

## 六、一句话

**机器查合规，人查违和——三轮下来机器的词表已经补齐了所有已知类，人的最后一轮只为未知类和"读不读得通"保留。这一轮之后，人工核查从流水线工人转岗为消防队：不站岗，只出警。**
