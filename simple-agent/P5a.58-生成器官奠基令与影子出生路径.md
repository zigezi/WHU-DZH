# P5a.58 — 生成器官奠基令：影子出生路径与自治边界

> 背景：τ 线哨兵模式稳态，裁决队列清空；P5a.54 立法"未来代码域免疫的天然基板 = 系统自己的算子执行日志"。缺的那块是**生成器官**——让资产的产生不再依赖裁决人逐案手工。
> 裁决：**自本令起，工作主线转向生成器官构建。医院暂缓（顾问线，触发线未至）。**

## 一、勘误

field_validated = **6 件**（lock_order / items_count / non_delivered / avail_enforce / payment_enforce / giftcard_enforce）。P5a.57 的"5 件"漏记 56b 已批升级，维持 6，不回降。——裁决人算术错误，opencode 核账正确，记档。

## 二、生成器官设计（五环 + 一条出生路径）

**五环管线**（自动化现状 → 目标）：

| 环 | 现状 | 器官化 |
|---|---|---|
| 开采 | p5a36 脚本（自动） | 触发化：新 run 批次落盘即跑 |
| 分诊 | 五类预分类（半自动） | 全机检：可观测性证明 + 死因归类 + 可拦截性判定 |
| 谓词起草 | opencode 手工 | **LLM 起草器**（尸体簇 → 谓词规格 + 干预语义初稿）——管线中唯一允许 LLM 的格子 |
| 金丝雀 | 手工建电池 | 半自动：死亡案例自动生成阳性探针，合法形状库自动生成阴性对照 |
| 认证 | C-1 已自动 | 不变 |

**出生路径（本令的核心设计）：影子模式（shadow）。**

新资产一律先出生为 **shadow 状态**：拦截器在线运行但**只记日志不否决**——"我本会在这一步拦你"。影子期毕业条件：累计 ≥10 次影子点火且**零影子误伤**（对最终 PASS 的 run 点火 = 影子误伤），自动转正 active；出现影子误伤 → 自动降级回炉，事件上报。

这是从静态审计到活体信任之间的桥：金丝雀证明笼子里对、追溯审计证明历史里对、**影子期证明在眼前这条 run 里对**——三级验证，token 成本为零的第三级。

## 三、自治边界（器官永不许做，宪法级）

1. **永不触碰奖励函数/验证器**（ τ 判分、单测、隐藏测试）——隔离墙不可穿越；
2. 永不编辑测试与金丝雀电池；
3. 永不自行变更 taxonomy/值分类法/死因分类法（变更 = 事件，出警人类）；
4. 可观测性证明失败者永不许进入影子期（P5a.56 出生要件，机检执行）；
5. 无影子证据者永不许转正；
6. 器官产出的一切（候选、草稿、影子日志）进证据域，但不进提交域——**commit/push 权限永远在人手里**。

## 四、建造纪律（防发热的自我约束）

1. **MVP 即止**：五环自动化 + 影子路径建成即停，不做任何投机扩展；
2. τ 无新尸体——器官建成后**空转待命是正常的**，它的第一批真材料是未来算子执行日志（P5a.54）或新域基板；空转不等于白建，就像消防栓；
3. 建造全程零模型 token（LLM 起草器联调除外，记小账）；
4. B-3 schema 增 status=`shadow`、字段 shadow_firings / shadow_misfires。

## 五、一句话

**免疫系统学会了生孩子，现在给它一间产房：孩子在影子病房里先证明自己不咬人，再上岗。从此资产出生不需要我签字——但产房的地基还是我画的。**
