# P5a.99 — 病院激活与数据集改造路由令（基线路径驳回 / 夹具池工厂采纳 / 信任边界封闭证明）

**编号**：P5a.99
**签发日期**：2026-10-16
**事由**：用户提案——由多智能体病院评估并改造现有公开数据集以符合五约束（无污染/锚可达/长链天然/确定性可判/谱系可建），K3 判价值与终验，迭代至试运行数据被认可；动机："人工抽查也会发现一堆问题，为什么不花 token 加速"。
**裁决**：**采纳一半，驳回一半。** 病院激活为**夹具科**（fixture 工厂）——采纳；病院改造公开数据集**进基线**——驳回（三约束不可改造）；病院触碰现行语料链（raw/deid）——**信任边界循环违反，物理封闭**。

---

## 一、先敬直觉，再修落点

"花 token 换人工锚的时间"——方向正确。锚带宽是全系统最稀缺资源，A3 三轮拉锯的账单大家都看见了。但 token 能不能换时间，取决于活在哪一层：**测量面之外、信任边界之外，token 是杠杆；测量面之内、信任边界之内，token 是污染源。** 提案的落点偏在把病院对准了基线材料和语料链。

## 二、驳回：三约束不可改造（证明）

改造能改变数据集的**内容**，治不了它的**属性**：

1. **无污染 = 历史属性，不是内容属性。** 公开数据集被模型"见过"这件事发生在过去，任何改写、重组、换皮都不能撤销历史——且近重复与结构记忆使"洗白"不可验证（污染检测本身无解）。病院可以抛光一个数据集一万遍，它也不会变回"没见过"。
2. **长链天然 = "天然"即约束本体。** 病院造出来的跨文档长链是人造结构——**人造即 fixture，by definition**（a83/a87 池分离）。RQ1 要的是自然发生的过程长度梯度与依赖，伪造梯度测出的是伪基线。
3. **锚可达 = 用户的领域能力，agent 劳动改变不了它。** 法律域用户已自报"不好人工断言"。且须点破提案里的一处角色错位：**K3 的"认可"背书得了程序合规（谱系链建成、变换留痕、电池全绿），背书不了领域真实**——我没有法律域的 ground truth，a82 已立法：文书审查 ≠ 代码审计，同理 K3 验收 ≠ 领域锚定。没有锚的域，迭代替"被 K3 认可"只是机器互证的空真，高一级形态。

## 三、封闭证明：病院碰不得现行语料链

提案若含"病院预筛 deid 副本、加速抽检"，此路循环违反：
- raw 含 PII → 发外部 API = 泄漏本身（DC-7）；
- deid 副本的**残留物就是 PII** → 查残留必须把疑似 PII 放进上下文 → 发外部 API = 查漏即泄漏；
- 本地无模型可用（a84 GPU 否决在案）。

**故"用外部 LLM 加速 PII 抽检"物理封闭，勿再提。** 这不是预算问题，是几何问题。

## 四、采纳：病院激活为"夹具科"（fixture 工厂）

fixture 的 ground truth **由构造保证**（注入什么缺陷，真值就是什么），不需要领域锚——所以"LLM 生成 + 确定性电池验证"构成**无锚闭环**，这才是 token 真正换时间的地方：

1. **产线**：公开数据集（法律类及其他）→ 病院改造（缺陷注入、变体生成、fixture 化）→ 规则电池/探针确定性验证（产出必须复现注入真值）→ K3 程序性验收 → tier=fixture 入夹具池。
2. **纪律**：fixture 永不入基线、永不上 smoke 测量面（a83/a87 池分离不动）；病院产出的每批 fixture 须过电池全绿，批次留指纹。
3. **试运行/dry-run 材料同路**：不进测量面的管线试跑，可自由使用病院改造的公开数据——dry-run 不测能力，只验管线。
4. **首道门**：电池验证全绿 + **工厂级锚定**（用户对工厂流程抽样锚定一次，不逐件审 fixture）+ K3 程序性验收。病院由此激活，编制暂限夹具科一科；Qwen3.8 试用状态与医院既有触发线维持原案，本科不占用其触发条件。

## 五、人工锚的正确加速法：带宽倍增，不是替代

信任边界之内，锚不可替代（DC-10 两轮机器空真，皆是锚破的——"人工抽查发现一堆问题"不是锚低效的证据，是**锚不可替代**的证据）。但锚带宽可以倍增：

- **确定性探针产出"可疑项清单"**，格式化呈锚（命中行 + 上下文 ±2 行 + 疑似类别），锚只判 flagged 项，不再通读 2756 行——两层制已在跑，本令把呈锚格式立为规范；
- 探针是确定性仪器（a85 红线不破），它**生成候选**，锚**裁决**——提议与处置分离，各就其位。

## 六、签发

病院夹具科激活，门条件在档。基线路径与语料链路径对病院封闭。锚带宽倍增格式立法生效。#9/#11 双门流程不变——opencode 回执澄清 P2-02、用户复检 4 件、#11 Diff 确认，照旧推进。
