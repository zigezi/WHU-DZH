# P5a.107 门套尸体登记与同源世界模型盲区定理令

裁席：Kimi K3（任务书裁席）｜日期：2026-10-19
缘起：用户命题——「四轮机器全绿、人类全红，何尝不是一种尸体」

## 一、命题采纳，并精化：是尸体，而且是两具叠放的

- **尸体甲**：脱敏器推测推断层——a106 已送四级架构重估，生死待决。
- **尸体乙**：**验证门套本身**（召回探针 / 闭包探针 / 字符断言 / fixtures / 规则电池 / 回归扫，六门四轮全绿、四轮全红）。尸体乙更危险：它是被信任去看管尸体甲的仪器。仪器死了可以修，**看管仪器的仪器死了而无人察觉，才是系统性死因**——本轮由用户点破，登记在案。

## 二、尸体乙初剖：六门同根一因

逐门死因（详剖令 opencode 入四级回执）：

| 门 | 申报所验 | 实际漏类 | 同根因 |
|---|---|---|---|
| 召回探针 | 映射表登记表面形 | 大小写变体（Volo） | 只验已登记形 |
| 闭包探针 | 已知实体锚变体 | 英文作者列 | 锚集之外无概念 |
| 字符断言 | raw↔deid 多重集差 | 该遮未遮（方向外） | 只验"多删"不验"少遮" |
| fixtures | 设计者可疑类 | 水印字嵌入常用词 | 只验已疑类 |
| 规则电池 | 归一化/规则文本 | 生产管线分歧 | 够不到管线 |
| 回归扫 | 已修法类 | —（守住了，唯一称职） | — |

**定理化：凡与所验仪器共享世界模型的门，对该模型的盲区结构性全盲。** 机器绿只能证明"已疑类已修"，永不能证明"未疑类不存在"。a92 空洞真教条是此定理的第一实例（已知映射量程），本轮给出机制本身：**盲区不可自证，因为造门的人和造仪器的人疑的是同一批东西**。

推论：人类锚不是流程补丁，是**架构必需**——锚是唯一不与机器共享世界模型的神谕。E2 域五约束之「锚可达」自此从务实条款升格为结构性条款。

## 三、元学习登记：这是 DC-10 产出的最重标本

1. **4-0 配对记录 = 带标签的门盲数据集**：同输入、机器判/人判成对、每轮盲类明确（召回 → 过遮 → 吞字 → 跨文种/大小写/表内嵌入/域尾碎片）。「机器门盲什么」的首个实证分布。
2. 死的不是脱敏器，是**验证过程**——过程之死正对 RQ1 胃口：过程死亡 ∝ 过程长度 的域外姊妹标本：**验证过程死亡 ∝ 门与仪器的世界模型同源性**。
3. 注意收敛的真实形状：**修复不复发**（四轮已修法类零回归），已知类集合单调增长——收敛发生在**类层级**，不在轮层级。四级方案（最小遮蔽核心 + 一次人工校正）的设计意图正是把剩余未知未知类一次性压进锚视野，而非再赌一轮机器。
4. 尸体与标本的区别只在登记与解剖。未解剖的 4-0 是挫败；已登记的 4-0 是课程。

## 四、令

1. **尸体农场登记**：DC-10-GATE（双层尸检件：脱敏器推测层 + 验证门套）。四轮配对记录原件归 `.agent/local/` 敏域，哈希入证据。用户语「四轮机器全绿人类全红何尝不是一种尸体」录为标本命名注脚。
2. **opencode 四级回执增载「门套尸检」节**：逐门列 申报量程 / 实际漏类 / 同源根因；并交新门设计三铁律落地方案——
   (i) 探针从**规格与失败类分类法**生成，禁与实现同源；

3. **预防性立法**：冒烟门套（#10 运行接线）上线即适用同一三铁律——避免第五具尸体。
4. a106 全部令项维持，本令为增载不替代。
