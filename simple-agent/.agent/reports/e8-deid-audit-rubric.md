# e8 脱敏库人工抽检 Rubric（v2，可操作判据）— P5a.35/37

> **判定对象 = 注入物（先例计划）文本本身**。不判接收任务、不判 agent 轨迹。
> **只判"脱敏质量"，不判"计划内容是否合理/完整/能否成功"**（a35 §二）。计划里的搜索/动作对不对、路线通不通，**不属本 rubric**。
> **④ 是机器判**（映射表逆向 + DB 全量字典，已全库通过）——人工不判④。
> 输出格式：`Case NN: ①T/F ②T/F ③T/F ⑤T/F`，每项附一句证据（引哪个值、哪两处）。

---

## ① I-III 类：全为类型前缀伪真值，且无裸真值

**I 类（实例标识符）**：`order_id`、`reservation_id`、`user_id`、`payment_id`/`payment_method_id`、`item_id`/`item_ids`、`product_id`、`certificate_id`、`flight_number`。
**III 类（个人标识）**：`name`（first/last/全名，**含自由文本里的人名**）、`email`、`phone`、`address`/`address1`/`address2`、`city`、`zip`。

- **PASS**：上述每一处都是**对应类型前缀伪真值**
  （`RES_` `ORD_` `USR_` `PAY_` `ITEM_` `PROD_` `FLT_` `CERT_` `NAME_` `EMAIL_` `PHONE_` `ADDR_` + `_0x…`），
  且**无任何裸真值**——包括嵌在自由文本 `summary`/`thought` 里的。
- **FAIL**：出现任一裸值。示例：`IFOYYZ`（预订号）、`1656367028`（product_id）、
  `yusuf.rossi@example.com`、`1979-07-12`、`123 Elm Street`、`92133`。
- **注意**：① 是"值类覆盖"判定；**不因"该值是不同实体"而 F**（那是②的误用，见下）。

## ② 共指一致性（同一实体→同一假值；不同实体→不同假值）

- **PASS**：同一源真值在注入物内**全程同一假值**（如 `get_reservation_details` 的 `<RES>` 与后续步骤的 `<RES>` 同号）；
  且不同源真值**没有被映成同一假值**。
- **FAIL**：同一实体两处假值不同（共指断裂）；或两个不同实体共享同一假值（虚假共指）。
- **常见误判（a35 实案）**：同一工具类型出现两个**不同**的候选值（如 `search_direct_flight` 的
  `destination=PHL` 与 `destination=EWR`）——**这是两个不同实体，不同值恰恰正确** → 判 **PASS**。
- **检查法**：对每个 I/III 假值，回看左右对照确认"同真值→同假值、异真值→异假值"。

## ③ 关系保持（日期 / 数值金额）

- **日期**：全体日期加**同一固定偏移**（本库 +1007 天 → 年份整体后移）。**PASS**：日期间的
  **先后与差值**与原始一致；`search` 与 `update` 的日期对齐；"相对今日"的关系不变。
- **数值/金额**：同一比例缩放（本库 ×1.37）。**PASS**：数值的**大小关系与量级**保持（100<200 缩放后仍 <）。
- **FAIL**：日期被**随机化到某个日/月**（破坏先后/差值）；金额被无关联替换（破坏比例）。
- **注意**：绝对年份变化（如 2024→2027）是**预期**，不判 F。

## ④ 无原始真值 —— 机器判，人工跳过

机器 = 映射表逆向断言 + **DB 全量实体字典**（11,014 值）词边界扫描，已对全库 443 计划通过。
人工一律标 `④机器已过`，不投入判读时间。

## ⑤ IV 类（封闭词表）约束

IV 允许保留裸值，但**仅限封闭词表成员**：

| IV 词表 | 允许的裸值 |
|---|---|
| 机场码 | IATA 3 字母且属环境机场集合（ATL/PHL/EWR/…） |
| cabin | economy / business / basic economy / first / premium economy |
| flight_type | round_trip / one_way |
| insurance | yes / no |
| state / country | 州名（TX/CA/…）、USA 等 |
| 小整数计数 | passengers / baggages 等 |

- **PASS**：出现在这些 IV 键位上的裸值均为上表成员。
- **FAIL**：**词表外的裸字符串**出现在"本应是实体"的位置——
  例如自由文本里冒出未脱的**城市名/品牌名/商品名**（按 a37 §三，商品名当前归 I/从严，裸现即 F）。
- **注意**：IV 裸值**不被 CopyGuard 视为答案值**（a35 §二 法理）——保留=合规，不是漏脱。
