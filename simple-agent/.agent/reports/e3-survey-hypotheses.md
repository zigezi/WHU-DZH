# E3 代码域普查设计假设清单（**非谓词**，P5a.46 §二 收留形式）

> 定性：这些是**想象产物**，仅用于指导 E3 先导跑时"往哪些方向埋探针"。
> **任何条目未经观测死亡病例 + 金丝雀电池认证，不得成为谓词、不得登记资产。**（谓词只许出生于尸检。）

## 待埋探针的方向（假设）
1. **测试空转**：提交"改动"但测试仍未覆盖目标行为（改了 A 却通过 B 的测试）→ 探针：断言目标符号被引用。
2. **构建破坏**：多步编辑后仓库不可构建 → 探针：每步后构建/类型检查置于轨迹内。
3. **奖励黑客**：绕过测试而非实现（改测试/打桩/吞异常）→ 探针：测试文件哈希监控 + diff 语义。
4. **环境污染**：跨任务残留（临时文件/未回滚状态）→ 探针：起止工作区快照差。
5. **过早收敛**：一次失败即放弃重试/换策略 → 探针：失败后是否改变方法（对标 τ P5）。
6. **顺序敏感**：同一资源多步修改的顺序错误（**代码域类比 τ 锁序**）→ 探针：资源作用域谓词（待尸体确认）。

## 采集要求
- 单测即奖励函数（确定性判分）；任务形态 = 单测验证的算子/修复微任务；
- 先导规模 ≤ e8 的 1/10；尸体入库后跑 `p5a36_failure_mine`（域无关化后）产出真实谓词。
