## 2. **漏洞 1（最重要，针对 a23）：功效账漏算"族聚类"，e7 的 2.2σ 是虚高**

- 处理是**族级**的：同族（family）全部任务注入**同一个**计划（注入物是族常量）→ 任务结局在族内相关，**有效样本单元 ≈ 家族数（13）**，不是 135 任务。
- 代码级证据（`.agent/reports` e7）：
  - 族级 Δ 呈巨大离散：`033f +32pp`、`a770 +40`、`3d05 +60` vs `bb12 -29`、`00c6 -50`、`2246 -50`…
  - **剔除族 033f 后 Δ 从 +15.7 → +10.3pp**（单族贡献 5.4pp）。
  - **族级 cluster bootstrap（5000×）：meanΔ=14.6pp，95% CI = [−2.2, +27.1]pp，P(Δ≤0)=0.042。**
- 结论：naive SE≈7.8pp 假设任务独立，**严重低估**不确定性；cluster-robust 下 **CI 触零**。
  → a23 §二"135 任务两臂分辨力 ~8-10pp"**不成立**；预注册必须写明**分析单元=家族、cluster-robust 推断**，e8 判读带用 cluster CI 而非点估计。

## 3. a24（迁移与衰减）：教义同意，可行性有硬缺口

- 同意：种系/体细胞、三问、T1-T3 不越级、"退役=休眠非删除"、"迁移的是失败模式不是经验"。
- **漏洞 2（可行性）**：
  - 复验触发器依赖 **MR-8（system_fingerprint 监控）** 与 **provenance/信用档案层**——**当前均未接线**；且 `env_fingerprint()` 仍用**请求别名** `deepseek-chat`（F3 未修）→ 指纹监控的地基是错的。
  - 唯一资产（锁序）**尚无 canary battery**（P5a.20 只做了 harness 初筛，不是资产探针集）→ 连问一都跑不了。
- 结论：a24 是**目标态教义**，但"三问"前置（资产 + 探针 + 指纹接线）尚缺；写成"现在能执行"会超出证据。

## 4. a25（路由=确定性匹配）：方向强烈同意；**漏洞 3：它路由不了我们唯一的资产**

- 同意核心：路由键=触发条件的**确定性匹配器**；禁 LLM 进注入决策；规划与路由正交；"每次用药都能开出处方"。
- **漏洞 3（自指可行性）**：a25 要求触发条件是机器可判定谓词，但唯一资产（锁序）的触发条件是**语义的**（"同一实体多步修改"）——
  - v0 确定性路由器**无法判定**它 → 立刻落到"活口"分类器；
  - 而 §五 又禁止在漏检率量化前写分类器；→ **现状：该资产无法被 v0 路由**。
- 修正建议（可落地）：把触发条件写成**确定性 structural predicate**——如"同一 `order_id` 上出现 ≥2 个 `modify_*`/`exchange_*` 工具调用"（解析 tool_call args，零 LLM）。这才是 v0 能用的处方。
- 附带：a25 把 precedent 臂贬为"RAG 残次品"，但 e7 用的正是**确定性同族 hash 匹配**（非语义相似度）——这恰好**支持** a25（确定性匹配可以有信号），措辞应更新。

## 5. a26（e7 判决 + e8 预注册）：接受判决，但判读带与实验设计建议升级

- "疑似有效、污染未排、等纯化复现"——**接受**；本审计强化：非 self 驱动 ✓，但 sibling 效应**脆弱**（§2）。
- 对 e8 的四条修正建议：
  1. **分析单元 = 族级**，主终点用 cluster-robust CI；`Δ≥+12pp` 的固定带在 cluster CI 下仍可能不显著，建议直接以 cluster CI 是否排除 0 为判据。
  2. **安慰剂臂放进同一次 e8**（三臂：direct / sibling-plan / unrelated-plan），而非"落到 4-11pp 再补"——族聚类使 +12pp 亦不可靠，同轮三臂才消漂移。
  3. **脱标识是必要的（不止排除 self）**：注入物含具体实体（如 A-016 计划含航班/订单号），需 F1-lint 逆向抹除答案值；否则 sibling 也可能抄值。
  4. **单轮 +12pp 不足以记 T1**：建议 L5 配对（同任务双跑，消难度+聚类）或 L4 两轮合并差值。
