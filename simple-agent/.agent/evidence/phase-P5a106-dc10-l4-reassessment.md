## 三、探针量程声明补正（a106 §三“探针同染”）

现行探针（召回/闭包）只覆盖“**映射表登记的表面形**”，未声明且未覆盖：
1. **大小写维度**（`VOLO` vs `Volo`）——须大小写折叠后比对；
2. **引用块维度**（英文作者/标题整块）；
3. **域尾/电话碎片维度**（`nai.com`、`185030`）；
4. **表格嵌入维度**（代号嵌入单元格）。

**补正**：探针报告须显式列出上述**未覆盖维度**（不得再以“residual 0”暗示全覆盖）；探针变体仅从实体生成，但须包含**大小写折叠、空白/连字符折叠、块级整块**三种；块级与碎片维度在 (a)/(c) 实施后由 fixture 覆盖。探针设计须**对抗匹配器实现**（规格级），不得与实现同源（a92 空洞真教义）。

## 四、引用块整块遮蔽规则设计（(a)/(c) 路径，确定性）

**目标**：参考文献/引用块内任何碎片（作者、标题、期刊、年份）皆可反向重识别，故**整块单代号**、不做部分遮蔽。

**确定性判定（按序）**：
1. **起点**：行匹配 `^\s*(参考文献|References|Bibliography|引用文献)\s*$`；或引用编号行 `^\s*[\[(]?\d{1,3}[\])]?[\.\s]` 且下一行含“作者列表 + 引号标题 + 期刊/年份”形态。
2. **块体**：自起点起，连续匹配“引用形态”的行（含英文人名逗号列表 / 引号标题 / 期刊名 / 4 位年份 / 卷期页）为块；遇空行≥2 或下一章节标题终止。
3. **遮蔽**：整块非空白字符替换为单一代号 `【REFS-】`（块内可保留一个标记），**保留原换行数**（行数守恒）；块内所有字母/数字/CJK 不留。
4. **保守扩展**：块内若检测到 `doi`/`http`/邮箱/数字串，仍整块遮蔽（不单独判类）。
5. **fixture**：合成引用块（英文作者+标题+期刊+年份）→ 断言单代号、无任何作者/标题 token 残留、行数守恒；负例：正文中的普通引用句（非块）不被整块吞（边界判定）。
