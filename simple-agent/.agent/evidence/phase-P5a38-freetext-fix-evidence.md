# P5a.38 落地证据：自由文本泄漏修复（商品名变体 + 表达式裸金额）

**依据**：P5a.38 §二 工单。病灶 = 自由文本替换器（结构化通道 v2 已干净）。

## 1. 修的四处
| # | 病灶 | 修法 |
|---|---|---|
| 1 | 商品名**变体重现**（`"the hose and backpack"` 裸现，字典只做精确匹配） | `_dbscrub` 改**词界 + 大小写不敏感 + 复数 s? + 多词名拆词元**（NAME/PROD） |
| 2 | `expression` 里**裸金额**未被缩放 | 字符串内金额形态统一走 II 缩放：`_RE_DEC`（含裸小数与 `$`）；`expression` 走 `_scale_all_numbers`（整数也缩） |
| 3 | 顺序错误：先实体替换后缩放 → 伪真值被二次缩放（`PRICE_0.00x…`） | 重排：**先日期平移/金额缩放，再实体替换** |
| 4 | `expression` **双重缩放**（`_scrub` 已缩 + `_scale_all` 再缩） | expression 走 `_scrub(money=False)`，仅 `_scale_all` 缩一次 |

## 2. 机器④ 升级（P5a.38 §二.3）
- DB 字典纳入**价格**（PRICE 3,414；商品名随 NAME 词元扩展）；
- 价格判据改**文档内可解释性**：deid 的两位小数必须能由**同文档原始数值 ×1.37** 解释，否则判残值
  —— 避免稠密价格库的撞号 FP（如 165×1.37=226.05 恰等于另一价格）。
