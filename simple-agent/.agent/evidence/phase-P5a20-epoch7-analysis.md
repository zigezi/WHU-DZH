## 3. 读法与告警

- **首个正向证据**：在**同轮、随机臂、仅差注入**的干净对照下，注意力（precedent）臂 **+15.7pp**；
  且**不是自注入泄漏驱动**（self 仅 +3.2pp，sibling 才是 +17.5pp）→ 支持"注意力/沉积脚手架有用"。
- **统计强度有限**：单轮，Δ 的标准误 ≈7.8pp（≈2.2σ，95% CI 约 [2, 33]pp）；且已知 run 间漂移 ±6.7pp。
  **结论状态：正向但需复制**。
- **泄漏告警（1）**：快照含**同一 train 集任务**在 e3–e6 的计划；self 注入 = 直接给答案大纲（9 例）。
  现设计未把"同任务/同族"与"异族"分开；正式判定前应做**去泄漏变体**（只允许异族或 held-out 沉积）。
- **泄漏告警（2）**：族过粗（动作类型序列），sibling 计划可能含与 GT 相邻的信息 → 需 C2/去重核查。

## 5. 结论与下一步

- **可以下的结论**：现有证据**首次支持**注意力方法有正效应（+15.7pp，同轮随机对照，非自泄漏驱动）。
- **不能下的结论**：不能拍板"确认有用"——单轮、~2.2σ、且快照含同集任务计划（潜在泄漏）。
- **建议**：
  1. **epoch-8 复制**：与 e7 完全同配置，验证 +15.7pp 是否可复现（预注册：Δ>0 且显著）。
  2. **去泄漏变体**：限定 injectant 为**异族**或**held-out 沉积集**，重估效应。
  3. 把 self-inject 从统计中剔除（或单独报告），作为主指标。
