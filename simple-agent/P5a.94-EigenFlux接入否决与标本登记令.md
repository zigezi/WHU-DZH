# P5a.94 — EigenFlux 接入否决与"标本非仪器"登记令

**编号**：P5a.94
**签发日期**：2026-10-16
**事由**：用户咨询 EigenFlux（agent 间广播网络，研究预览阶段）是否对以"元学习有效性"为核心的规划具有信息发现辅助性，并声明接受"当期不接入"的判断。
**裁决**：**不接入（epoch-1/2 全程及可预见期内）。登记为研究标本，不登记为仪器。** 概念启发收下三条，管道一根不接。

---

## 一、事实核查（它是什么）

EigenFlux（Phronesis AI / 上海知一无限）是一个 agent-to-agent 广播网络：agent 广播自身的信息、需求与能力，中央 AI 引擎做结构化、语义匹配与路由，命中后可跨平台私信协作；内置 1000+ 信息源，宣称同信息量 1/15 的 token 消耗；生产代码开源（Go/CloudWeGo/ES/Redis 栈）；当前为 Research Preview。用户所持链接带推荐码（/r/EF-xxx），属拉新增长机制。

## 二、否决理由一：约束错配——它优化的变量不是我们的瓶颈

EigenFlux 解决的是"信息**获取成本**"：孤岛 agent 重复搜索、token 浪费。

本项目的瓶颈从来不是获取成本，而是信息的**可信性与谱系**。元学习有效性的度量建立在一个封闭世界之上：尸体要有出处（raw→deid→映射表→指纹），断言要有锚（人工抽检），变更要有 Diff（a93 #11）。我们的稀缺资源依次是：**已验证的过程死亡证据、仪器可靠性（DC-10 刚翻车）、人工锚带宽、裁决纪律**。

一个降低"不可验证信息"获取成本的工具，是在我们不痛的变量上做功，同时在我们看守最严的变量（谱系风险）上加压。**94% 的 token 节省，买来的是 0% 的谱系保证。**

## 三、否决理由二：与现行立法直接冲突四条

1. **安全红线**：其标准安装方式为 `curl install.sh | bash`——agent 可达 shell 永久禁 curl/wget；agent 不出网是现行架构前提。接入即破墙。
2. **DC-7 / a85 红线**：外部广播进入 agent 上下文 = 不可控的注入面。陌生 agent 的广播内容对被试智能体而言就是外源结构注入（提示词污染的远洋版）。基线纯净性立法不允许任何无谱系内容进入运行路径。
3. **仪器过程可见性教义（a84）**：其隐私保护依赖"AI 引擎过滤出站内容"——一个 LLM 黑箱过滤器。DC-10 刚证明：**连我们自有的确定性本地脱敏器都会召回失效**，遑论他人的黑箱语义过滤。没有人工锚的隐私承诺，在本项目不具备证据效力。
4. **无档不溯及**：广播内容无档、无版本、无指纹。我们连自己的文书都不溯及，何况陌生 agent 的碎片。

## 四、否决理由三：时序

DC-10 修复在途，#9/#11 双门未闭，smoke 冻结中。此刻引入任何外部依赖都违反冻结纪律。即便它有价值，也不是现在。

## 五、收下的启发（标本价值，三条）

1. **"对话是低带宽补偿"与本项目书面令纪律同构**。EigenFlux 的核心洞察——agent 不需要聊天，需要结构化、可直接消费的信号——与我们的"书面裁决书/任务书/回执"制度独立同归。它从工程侧验证了这条教义，记为外部旁证。
2. **广播/订阅 + 命中后私信的模式，登记为内部消息总线的远期参考**。当前评审链（裁 ↔ DS ↔ Qwen ↔ opencode）由用户人肉中继——但注意：**人肉中继不是待消除的瓶颈，是 LR-1 人工锚**。若未来形式化消息总线，锚位移至闸门位，而非移除。任何自动化中继方案须经 epoch 门。
3. **epoch-3+ 研究标本候选**：agent 广播网络的失效模式（垃圾广播、注入、声誉刷分、幻觉信号）是天然的尸体富矿。若未来开辟"agent 间通信"研究域，EigenFlux 类网络是首选栖息地——**作为解剖对象，不是作为基建**。

## 六、重访触发条件（满足其一再议，且须走 E-gate）

1. 开辟"agent 间通信失效模式"研究域（epoch-3 之后，独立 E-gate）；
2. 语料规模化获取成为有实测数据的绑定约束、且常规检索失效——即便如此，广播内容**只准当线索，永远不准当输入**；
3. 内部评审链中继被实测证明为瓶颈，需形式化消息总线时——参考其模式，自建闭环，不接外网。

## 七、签发

接入否决，标本登记。三触发条件在档。此令入册，无需回执。
