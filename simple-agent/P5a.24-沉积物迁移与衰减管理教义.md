# P5a.24 裁决：沉积物迁移与衰减管理教义

**仲裁人：Claude（任务书作者）｜日期：2026-09-29**
**问题**：沉积物被证明有效后，如何长期有效、跨任务跨数据集跨模型有效？"tau 中学到'数学必须代码计算'，以后在不同任务不同模型中也保留吗？"
**裁决：迁移的不是经验，是失败模式。有效性不是资产的属性，是资产的状态——有保质期、有复验触发器、有退役仪式。文本载体是种系，权重载体是体细胞表达：教义不因 P6 改变一个字。**

---

## 一、迁移原理：随触发条件旅行，不随数据集旅行

先回答"数学必须代码计算"这条。它为什么天然跨数据集？

```
这条规律修补的失败模式：
  「神经估计器对确定性可验证量进行猜测」

这个失败模式属于谁？
  ✗ 不属于 τ-bench
  ✗ 不属于 DeepSeek
  ✓ 属于整个神经估计器范式——任何 LLM、任何任务、任何领域
```

所以它的可迁移性不是"从 tau 泛化出去的学习成果"，而是**它一开始写的抽象层级就正确**（P5a.17 L2）：触发条件里没有任何 tau 特有实体，因此它在任何"触发条件在场"的地方自动生效。**迁移不需要迁移学习，需要的是规则适用——资产随其触发条件旅行。**

反例对照：

| 写法 | 失败模式归属 | 跨数据集 |
|---|---|---|
| "TAU-A-008 要调计算"（L1） | τ-bench | ✗ 死了 |
| "22h57m"（L0） | 单个实例 | ✗ 死了 |
| "凡判断依赖精确数值关系，先由确定性工具产出该值"（L2） | 神经估计器范式 | ✓ 活着，跟着触发条件走 |

**推论（强化 P5a.17）：入库时的 F1/F2 过滤不只是防污染，就是在决定资产的迁移半径。触发条件写得越脱标识、越贴近失败模式本质，迁移半径越大。宪法在入库一刻就预定了资产的终身流动性。**

## 二、进入新语境的三问（固定顺序，不许跳步）

资产被证明有效（T1，见下节）后，遇到新任务族/新数据集/新模型，**不默认携带，走三问**：

### 问一：失败模式在场吗？（便宜，先做）
- 用资产的 canary battery（P5a.17 第三过滤器编译出的探针集）在新语境跑一遍。
- 例：给新模型/新领域出 5 道"22h57m 类"计算题，看它估不估。
- **不估（失败模式不在场）→ 资产休眠于该语境，不注入。** 没有失败模式的地方打补丁是负收益（稀释，P5a.18 R1 同构）。
- 成本：几十次调用，无训练、无运行轮。

### 问二：补丁有效吗？（贵，问一为是才做）
- 同轮 A/B：注入 vs 不注入，按 P5a.23 预注册框架判读。
- **不赢 → 记录为"该语境下无效"，休眠。** 不删（失败模式在场但补丁不对路，是未来研究的线索）。

### 问三：值得吗？
- 赢的幅度 × 触发频率 > 注入成本（上下文预算税 + 混淆风险）？
- **不值得 → 休眠。** 值得 → 在该语境激活，记入溯源层。

**三问的产物是一份逐语境的「信用档案」，写在溯源层（不进注入层）：哪些语境验证过、证据级别、上次复验时间。**

## 三、信用级别：T1/T2/T3，不允许越级声称

| 级别 | 含义 | 证据要求 |
|---|---|---|
| **T1** | 同任务族内有效 | 同轮 A/B 胜出（P5a.23 一次） |
| **T2** | 跨任务族有效 | ≥2 个不同任务族各自过三问 |
| **T3** | 跨数据集/跨模型有效 | ≥2 个数据集或 ≥2 个模型指纹各自过三问 |

"数学必须代码计算"目前连 T1 都没有（其证据 A-008 已被判 harness 纠缠 + e6 时代该资产还没被验证性注入过）。**别笑——把这条写在纸面上，比凭直觉声称"这肯定泛化"诚实得多。直觉声称是这个行业泡沫的主要来源。**

级别只能逐级爬，每级留证据。**对外（论文）声称到哪级，溯源层必须能拿出哪级的全部同轮对照记录。**

## 四、衰减管理：有效性是状态，不是属性

世界在变：模型在换（MR-8 指纹）、任务分布在漂、API 行为在改（retail 的订单锁就是 API 语义，随时可能变）。所以：

### 4.1 金丝雀电池 = 回归测试套件
每个活跃资产的 canary battery 不是一次性入库考试，是**常驻回归测试**：
- 定期跑（每次 epoch 前顺手跑，成本极低）；
- 失败 → 资产自动降级为"待复验"，暂停注入，走三问问二。

### 4.2 复验触发器（不靠日历，靠事件）
| 触发器 | 来源 | 动作 |
|---|---|---|
| 模型指纹变化 | MR-8 system_fingerprint 监控 | 该模型名下全部活跃资产重跑问一 |
| 资产注入后同轮对照转负 | 测量架构（P5a.23） | 降级待复验 |
| 环境语义变化（如 API 升级） | 监控器 C4 类信号异常率突变 | 相关触发条件全部重跑问一 |
| 超期未复验（TTL，建议 90 天） | 溯源层时间戳 | 降级休眠，注入层自动摘出 |

### 4.3 退役 = 休眠，不是删除
失效资产保留在溯源层，标注失效语境与日期。理由：失败模式可能回归（模型版本回滚、旧 API 复活），休眠资产的重激活成本远低于重新发现。**资产库只进不出，注入层新陈代谢——这与"沉积"的地质学本义一致：岩层不消失，只是不再出露。**

## 五、文本与权重：种系与体细胞

P6（本地权重）改变载体，不改变教义：

```
文本沉积物（L2 文本）     = 种系（germline）
  - 模型无关、可审计、可版本化、随触发条件旅行
  - 是三问流程和信用档案的唯一法定载体

权重操作（ΔW）            = 体细胞表达（somatic expression）
  - 把文本规律"编译"进某个具体模型的参数
  - 每个模型指纹一份编译产物，不可跨模型携带
  - 编译后必须重新过问二（同轮 A/B）才算在该模型上激活
```

**"以后不同模型中也保留吗"的完整回答**：文本层永远保留（它是种系）；换模型时问一（canary battery）几乎肯定仍是"是"（失败模式属于范式）；问二对权重版本必须每个模型重做（编译产物不携带），对文本注入版本只需确认稀释税没变。**验证管线是载体无关的——这正是我们把验证架构建在文本层（P5a.23）而不是权重层的原因：权重会换，管线不换。**

## 六、操作性定义（收尾）

```
沉积物长期有效 ≡
  触发条件在目标语境持续在场（金丝雀电池为证）
  ∧ 该语境最近一次同轮对照仍胜基线（未超复验期限）
  ∧ 信用档案无未修复的降级标记

跨 X 有效（X ∈ {任务族, 数据集, 模型}）≡
  在 ≥2 个不同 X 上分别完成三问且问二为胜，档案记为对应级别
```

## 七、工程注记（仅登记，不解冻）

资产库 + 更新器队列 + L0 缓存长期增长后，7.3GiB 会撞内存墙。届时方向：注入层热集留内存、溯源层全量留 SQLite、Redis 仅做队列不做存储。现规模（1 个资产）无需任何动作，冻结继续有效。

至此沉积物生命周期三件套齐了：

```
入库：P5a.17 —— L2 限定 + 三过滤器 + 双层存储
验证：P5a.23 —— 同轮对照 + 双指标 + 操作性定义
```

**一句话教义：沉积物不是"学到了什么"，是"在哪类失败上打了补丁、这个补丁在哪些语境被验证过、上次验证是什么时候"。库里的每条资产都是一份带保质期的判决书，而不是一块纪念碑。**
