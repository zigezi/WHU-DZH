# P5a.59 — 生成器官点火令：两阶段验证设计

> 触发：器官 MVP 建成（organ.py，五环 + 影子路径 + assert_in_scope 宪法墙，自检 all_pass）；用户请示"再开一轮，生成看看效果"。
> 裁决：**批准，但分两阶段——先已知答案校准（零 token），后小规模活体验证批（硬顶 1.5M tokens）。器官是仪器，仪器先刻刻度再上产线。**

## 一、阶段一：器官已知答案校准（先做，≈零 token）

器官的自检证明管线不崩、宪法墙管用；它没证明的是：**器官的分诊判断与我们人工裁决的分诊判断是否一致**。好在标准答案现成——e1–e8 尸体库的 25 条候选，每一条都有人工终裁（8 部署 / 3 拆解后部署 / 2 驳回 / 9 收窄合并 / 其余处置）。

- 把 e1–e8 尸体库当作"新批次"喂给器官，产出与人类分诊终裁逐条对照；
- **预注册合格线**：(a) 驳回类（user_not_found、BookReservation.invoke）器官必须全拒——**误放 = 重罪**，一条都不可放过；(b) 8 个已部署资产的死因簇必须全收——误杀说明召回不足；(c) 其余条目允许分歧，逐条记录理由；
- ring_draft 的 LLM 调用记小账（预计 <0.1M）；
- **不合格 → 修器官重测，不许进阶段二。** 合格 → 器官获得"在已知地形上判断与人类一致"的校准证书，阶段二开闸。

## 二、阶段二：小规模活体验证批（双目的，硬顶 1.5M tokens）

这不是 epoch，是两笔登记欠债的偿还：

**目的 1：在役哨兵首次真开火。** P5a.56 案 2 但书 3 在案：良性再发的结局保持性静态不可证，留给在役干预日志。本次运行产生第一批干预日志，完成 lock_order_v1 从 field_validated(static) 到活体确认的最后一里路。

**目的 2：器官活体试产。** 新批次的尸体（若有）走完整五环：开采 → 分诊 → 起草 → 电池 → C-1 → **影子出生**（注意：新资产只进影子期，本次运行内不转正、不拦截）。

**批次设计**：15–20 任务，死亡陷阱富集——5 个锁死任务（R-041/072/098/105/058）全上 + repeat/支付/exchange 易发任务 + 少量对照；**7 哨兵全员在岗，不开 A/B**（这是验证不是假设检验）。

**预注册判读表**（先写后跑）：
1. **点火台账**：每资产每次点火、良性再发过程、结局——**拦截器把 PASS 改成 FAIL = 该资产立即回炉事件**，一票到底；
2. **陷阱任务存活率**：5 个锁死任务历史上全死于锁序——本次活几个；救场的机制证据 = 日志里可见"否决 → 改地址 → 重发 → 通过"的完整链；
3. **器官产出清单**：新候选若干、影子出生若干、误伤预警若干；
4. **禁能力声明句式**：不报"通过率提升/下降"，只报点火台账 + 救场案例 + 器官产出。

**发热门合规说明**：≤20 题 ≈ 1.5M 硬顶，非全域 epoch；目的是完成已部署资产的认证闭环 + 器官试产——属"带出部署资产"条款的履约，不是新假设检验燃烧。

## 三、顺序与停止线

阶段一 → 合格 → 阶段二 → 判读 → 器官要么持证上岗要么回炉。阶段一不合格则阶段二自动取消（没有刻好刻度的仪器不许上产线）。

## 四、一句话

**点火可以，但按仪器的规矩点：先对着旧尸体名单证明它的判断和我们一样，再放它去看新尸体。器官的第一课和资产的每一代一样——先证明自己不咬人。**
