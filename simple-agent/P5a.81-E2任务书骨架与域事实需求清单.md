# P5a.81 E2 任务书骨架（注册段起草）与域事实需求清单

日期：2026-10-15
依据：P5a.76 §二.2（注册段三方输入）、用户六问、E2 立法史（a41/a42/a43/a45/a67/a72/a76/a78/a80）

## 一、定位

E2 = 投标文件类长程真实任务基线 epoch。职责三条：真实长程泛化验证（a42）；规划问题的真实考场（a45，二期）；本阶段主尸源（a76）。

## 二、研究问题（预注册骨架）

- **RQ1（epoch-1，描述性基线）**：操作者在真实长程投标任务上的表现与死因分布；过程型死亡占比——a54"过程死亡∝过程长度"定律的域外检验。
- **RQ2（epoch-2 及以后，另立 E 门）**：规划臂 vs 无规划臂。epoch-1 不含任何规划干预——e8 刚证伪外源计划结构注入，不许借尸还魂。

## 三、哨兵激活机制（答"激活了没触发"）

域法律不变：**资产必须从本域尸体出生**。E2 epoch-1 以资产=0 开局：

1. 器官 ring_mine 批次结束自动消化（a61 §三.2 从 τ 批扩展至 E2 批）；
2. 尸体 → 候选 → 电池 → C-1 + naming_proof → 影子模式 → 部署，一要件不免；
3. τ 资产不带入 E2；repeat_failure 类通用族若入境须在本域重新出生；
4. "哨兵静默可解性"立法延伸 E2：接线证明之后，静默 = 模式未发生，非失能。

## 四、有用性判据（epoch-1 预注册）

1. 基线测得可信（ITT 分母纪律）；
2. 尸体产量与死因多样性达标（阈值随任务集规模定，任务书正文冻结）；
3. **≥1 件资产在投标域走完全生命周期**（器官首次跨域繁殖，核心判据）；
4. 硬线违例 0。

成功 ≠ 能力提升。能力侧任何读数只进台账不进结论。

## 五、尸体农场

双层：**建设段**喂 code_corpses（在跑）；**运行段**喂 e2_corpses（新域池，domain_pack="bid"）。采集仪器全套复用（工具层钩子 + 回合末收割兜底 + 任务级判定通道），条目绑定 git_head / env_fingerprint / schema_v（a80）。

## 六、预算控制

运行时闸（SA_BUDGET_CAP 模式，a60 §三）强制。三段预算：

1. 建设段：0 token；
2. 冒烟先导：3-5 题（实测单题成本，据此定 epoch 预算——长程任务单题开销大，禁止拍脑袋定总额）；
3. 基线 epoch：E 门预注册硬顶，超支登记纪律照旧。

## 七、成功定义（epoch-1）

§四四条全达即成功。预注册失败结论之一：若死亡全为能力顶死型（E3 式），入负结果册并回报"投标域基板无过程型死亡可拦"，不追加轮次。

## 八、域事实需求清单（用户作业）

1. **投标语料**：来源（真实历史投标文件？可否脱敏使用）、规模（份数/篇幅）、格式（docx/pdf/md）；
2. **任务集生成规则**：什么算一个"任务"（章节补全 / 合规检查 / 数字一致性核对 / 全文审查？）；目标 20-40 题；多样性轴（篇幅 / 章节类型 / 改动类型）；
3. **评测器**（最难，E 门核心）——三选一或混合：
   a. 确定性结构检查（必备章节、格式、数字一致性）；
   b. LLM 评审 + rubric + 人工抽检校准（P5a.35 抽检模式）；
   c. 纯人工金标准（小规模可行）。
   **裁者建议 (a)+(b)**：确定性检查兜底可程序化部分，LLM 评审覆盖语义部分，人工抽检做校准锚。

## 九、推进方式

触发式，无时间表：域事实齐 → 任务书成书 → E 门预注册 → 首跑。建设段（设施）与域事实采集并行，互不阻塞。
