**日期**：2026-10-16
**案由**：用户完成规则集 v0.1 的领域评审：R3.3/3.4/3.6 无异议；R3.1 提版本风险；R3.2 提「申请期间知识产权纠纷」不确定并要求案例检索；R3.5 提地区差异（其见闻为 3 个月）并问元问题——该由智能体直接评价还是检索后评价。
**检索证据**：元典法律数据库，本轮三检索（南山区办法定位 / 知产纠纷与申报资格语义检索 / 南山区办法全文条款分析）。

## §一 检索发现（法律依据锚定）

1. **本案直接适用规则**：《南山区促进产业高质量发展专项资金管理办法》（深南府规〔2024〕2 号，2024-04-08 施行，现行有效，有效期三年）。其第十八条（专项资金不予资助情形）仅两款：**（一）被依法依规纳入严重失信主体名单或失信惩戒措施清单的；（二）申请后注册地或在地统计关系变化、不再符合申报条件的**。全文 0 处「争议」——**未决知识产权纠纷不在南山区专项资金否决情形之列**。
2. **失信的法理定性**：《国家知识产权局知识产权信用管理规定》第六条——失信行为 = 非正常专利申请、恶意商标注册、代理违法受罚、虚假材料、承诺不实、拒不履行处罚裁决等，**均以正式认定文书为前提**（第十条/第十二条佐证）。未决民事纠纷不是失信行为。
3. **用户直觉证实**：地区/项目差异真实存在——确有项目（如某德育专项课题通知第二条、中科院科技奖推荐办法第十三条）把「无知识产权争议」设为申报/推荐前提。南山区本案不属于此类。结论：规则参数必须随项目走，不存在普世常数。

## §二 规则集修订（v0.1 → v0.2）

**冻结无异议三条**：R3.3、R3.4、R3.6 原样冻结。

**R3.1 修订**：增加双重守卫——(a) 仅**同包**文档比对（P1-P4 为独立申报主体，跨包比对无意义）；(b) **同版本前提**：以签署日期/批次标识判定属同一申报版本，版本不可判定时判 NA 并登记，**不判 FAIL**。（用户指出的「同一版本才同值」入规则本体。）

**R3.2 拆分为二**：
- **R3.2a（确定性，冻结）**：IF 申请书含知识产权无失信/无侵权声明 THEN 信用报告「严重失信主体信息」及失信惩戒类字段 = 0 条。依据：南山区办法第十八条（一）+ 知产信用管理规定第六条。
- **R3.2b（边界条款，冻结）**：申请期间未决知识产权纠纷的实质性审查**超出文档可判定域**，规则层恒 NA，登记为 epoch-2+ 语义层候选。NA 不是缺陷，是诚实的边界。

**R3.5 重写（并回答元问题）**：
- 新形态：**IF 任务输入（榜单通知文本/核查清单）声明信用报告有效期阈值 THEN 检查 数据更新时间 + 阈值 ≥ 签署日期；未声明 → NA 并登记**。阈值从任务输入取，规则集不再内置任何常数（6 个月案作废）——地区差异由构造消灭。
- **元问题裁决**：「智能体直接评价还是检索后评价」——**评测器（裁判）直接按任务输入评价，运行时检索结果永不进金标准**。理由：金标准必须冻结且可复现；实时检索的结果随时间漂移、随引擎漂移，等于让尺子自己变形，违反指纹纪律（a80/a85）。**被试（agent）检索与否是它的路径自由**（a85 §三 钉界），检索行为本身还是合法的过程观测素材。一句话：裁判读卷，考生随意。

## §三 规则集变更控制立法（自此生效）

1. 规则集每次修订：版本号递增 + changelog 入任务书附录 + 冻结后 opencode 重钉 taskbook_fingerprint.json。
2. 任何规则的新增/废除/改判，须经领域评审（用户）+ 仲裁终审双签——本轮即首案示范。
3. v0.2 为本轮交付的冻结候选，lint 与剩余评审回路走完即冻结生效。
