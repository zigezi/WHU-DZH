# P5a.23 沉积有效性测量架构（跨 epoch 死亡后的替代方案）

**裁决人**：task-book 作者 / 仲裁者
**触发**：用户提问——跨 epoch 不可比之后，如何判断沉积有效？
**地位**：测量教义。P5a.22 判"跨 epoch 比较永久死亡"后，本文件给出替代测量架构。未来一切"沉积有效"声明须按本架构取证。

## 〇、一句话原理

run 间漂移（±6.7pp）污染**水位**（绝对值的跨 run 比较），不污染**同轮内差值**（同轮各臂共享同一模型/key/温度/日期/仪器，唯一变量是注入内容）。
**口诀：比差值，不比水位。**

## 一、测量阶梯（L1–L5）

| 级               | 设计                                     | 测什么                                    | 状态                      |
| --------------- | -------------------------------------- | -------------------------------------- | ----------------------- |
| L1 同轮双臂         | 同轮 50/50 precedent vs direct           | L1 情景回放通道                              | **e7 在跑**               |
| L2 同轮 POLICY 开关 | 同轮按任务随机 50/50：wiki+POLICY vs wiki only | POLICY 通道纯净效应（"沉积有效吗"主战场；MERGE 死后唯一法庭） | epoch-8 候选，待 e7 结果后裁决发令 |
| L3 同轮多臂版本赛      | 同轮三臂：无沉积 / v1 / v2                     | 新沉积物晋升赛："有用吗"（vs 无）+"比旧版强吗"（vs v1）一轮同答 | 未来候选资产的默认赛制             |
| L4 差值合并         | 2-3 轮同轮对照，合并每轮臂间差值（meta 分析）            | 提升功效；差值自带漂移免疫，跨 run 合并合法               | 功效不足时启用                 |
| L5 配对设计         | 同任务同轮双跑（处理/对照各一次），McNemar 配对分析         | 难度自控、功效最高                              | 关键裁决专用（token 翻倍）        |

L3 赛制即沉积物晋升流水线：**updater 提案 → L2 宪法过滤（P5a.17 三关）→ 金丝雀门 → 以新臂身份进同轮对照 → 赢 control（及 incumbent）才晋升。** 路由器测量模式（固定随机化 + 快照冻结）已为此铺路。

## 二、两笔诚实账

1. **功效账**：135 任务两臂单轮分辨力 ~8-10pp；5pp 级效应须靠 L5 配对 / L4 合并 / 连续指标。预注册时必须写明用哪把尺子、最小可检效应是多少。
2. **尺子账**：通过率不是唯一尺子。沉积物价值可体现在效率——同通过率下 token/轮数减半也是真赢。每轮判读表带双读数：结局（pass）+ 成本（token/turns）。连续指标功效高于二值结局。

## 三、双门制的分工不变

- **金丝雀门**：机制声明。构造即真 + 轨迹断言，与模型漂移无关——本架构不触及。
- **通过率门**：结局声明。修复为本文件的同轮对照阶梯。

## 四、操作定义（宪法级）

**"沉积有效" ≡ 同轮随机对照下战胜无沉积基线（结局或成本其一，预注册指定），且机制断言过金丝雀门。**
两条缺一不可。缺前者 = 未证有效；缺后者 = 有效但不知为何，不得晋升。
