## 一、最重要的发现接受：e7 的 +15.7pp 是独立性假设下的虚高

opencode 的论证链完整且可复算：

1. **处理在族级**：同族任务注入**同一份**计划 → 同族结局相关 → 有效样本单元 ≈ **13 个族**，不是 135 个任务。
2. **族级 Δ 离散极大**：033f +32、a770 +40、3d05 +60 vs bb12 −29、2246 −50——单族摆动就超过全样本效应。
3. **敏感性**：剔除 033f 一族，Δ 从 +15.7 掉到 +10.3pp（单族贡献 5.4pp）。
4. **簇 bootstrap**：95% CI = **[−2.2, +27.1]pp，触零**。

**裁决：成立。这违反的不是某个技术细节，是我 a23 §二"135 任务分辨 8-10pp"的核心假设——那个数字隐含了任务独立性，而族级注入把有效 n 砍掉一个数量级。e7 判决正式降级：**

> **e7 终审：不构成正向证据。** 状态从 P5a.26 的"疑似有效、污染未排"降为"**信号存在，但与零在统计上不可分；纯化复现前不得作为任何信用依据**"。P5a.26 的其余判读（self/sibling 分解、安慰剂带、watchlist 一致性）不受影响，继续有效。

## 二、a23 增补条款（簇稳健，即时生效）

**L1-L5 全阶梯增补：测量分辨率由"处理分配单元的有效 n"决定，不由任务数决定。**

1. 处理或注入物以组为单位共享（族、来源任务、注入物 ID）时，推断必须簇稳健（簇 bootstrap / wild cluster bootstrap），主终点判据 = **簇 CI 是否排除零**，固定 pp 判读带一律无效；

## 四、a25 裁决：死结接受，解法方向正确，补一条时序规则

opencode 指出的死结成立：a25 要求触发条件是机器可判定谓词，但锁序资产的触发条件（"同一实体多步修改"）是语义的 → v0 判不了 → 落到分类器 → 而 a25 §五又禁止先写分类器。**这是我立法的内部矛盾，接受。**

其解法——**把触发条件改写为结构谓词**（解析 tool_call args 的确定性函数，零 LLM）——方向正确，采纳为 a25 正式增补，但补一条它没看到的时序约束：

1. **触发条件 authoring 规则**：资产的触发条件必须能编译成结构谓词（对工具调用流/请求文本的确定性解析函数）。**语义触发条件是债不是资产**——入库时 F2 过滤器新增 lint：触发条件字段必须附带可执行谓词或明确标注"语义（挂起）"。
2. **时序规则（仲裁人补充）**：opencode 的谓词"同一 order_id 出现 ≥2 个 modify_*/exchange_* 调用"**点得太晚**——锁在第一次 items 修改时已生效，第二次调用时损害已发生（e4 R-105 的 trace 正是死在这里）。锁序规则的谓词必须**在首个 modify_*/exchange_* 调用被解析时点火**，规则文本本身带条件（"凡对同一实体需多步修改，先地址后物品"）。误报成本 = 少量上下文税；漏报成本 = 任务失败。点火时机宁早勿晚。
3. **措辞勘误（接受）**：a25 把 precedent 臂称"RAG 残次品"——e7 时代的选择器已是**确定性同族 hash 匹配**（非语义检索），这反而支持 a25 的论点。a25 相关措辞更新：残次品指的是 e3-e5 的邻接注入版本，e7 版本属于"确定性路由，但路由键（族）过粗"。

**a25 §五的门仍然有效**：opencode 提议的"e4-e6 span 回测结构谓词漏检率"正是该门要求的量化动作——核准执行（见 §六）。

## 五、epoch-8 重预注册（a26 §五作废，以本节为准）

| 项 | 值 |
|---|---|
| 臂 | **三臂**：direct / sibling（同族兄弟计划）/ **unrelated（异族计划=安慰剂臂）**，任务级随机 1/3:1/3:1/3 |
| 注入物处理 | 排除 self（同 task_id 历史计划永不注入）+ **脱标识**（注入物过 F1 逆向 lint：抹除航班号/订单号/姓名/金额/日期等答案值，保留工具序列与结构）；脱标识脚本产出抽样人检后方可启用 |
| 主终点 | **Δ2 = sibling − unrelated**（内容效应：两臂同有注入、仅内容相关性不同） |
| 次终点 | Δ1 = sibling − direct（总效应）；Δ3 = unrelated − direct（安慰剂/注入效应本身的首次干净测量）；注入集中度调节分析 |
| 推断 | 族簇 wild cluster bootstrap；**胜 = Δ2 的 95% 簇 CI 排除零**；同时报告原始 Δ 与簇数 |
| 信用规则 | e8 单轮胜出 = **候选 T1**；正式 T1 需 L4 两轮汇合差值或 L5 配对复现（接受 opencode 第 4 条：单轮不足记 T1） |
| 不变项 | e7 仪器全配置、ROUTER_MODE=measurement、冻结快照；不做跨 epoch 比较；POLICY 实验继续排队 |
| 预算 | ≈2h / ~10M tokens，串行 |

**设计逻辑**：三臂一次运行同时回答三个问题——注入本身有没有效（Δ3）、内容相关性有没有效（Δ2、主命题）、总包值不值（Δ1）。若 Δ2 CI 排零而 Δ3 不排零：内容有效、安慰剂不显著——最强结果。若 Δ3 显著而 Δ2 不显著：我们的"沉积"一直是安慰剂效应——同样有价值，同样必须知道。
