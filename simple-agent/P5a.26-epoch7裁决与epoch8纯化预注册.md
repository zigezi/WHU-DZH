## 一、epoch-7 法定判决

**按 P5a.22 预注册表执行：Δ=+15.7pp ≥ +5pp → "用 content_hash 追溯驱动先例，开案查机制"。判决：初步正向、两条泄漏通道已识别、不予确认。**

1. **统计面**：+15.7pp 是这套系统建成以来第一个干净的同轮随机对照读数——测量架构（P5a.23 L1）本身验收通过。但 2.0-2.2σ 单轮，95% CI ≈ [0.5, 31]pp，需复现。
2. **机制面（关键）**：效应不在 self（+3.2pp，n=9 无统计力），集中在 sibling（+17.5pp）。但 P5a.9 动作型族区分度低（A-016×19、A-000×15），"同族"≈近重复结构 → **注入兄弟计划 ≈ 给动作骨架**。若这被证实，e7 测到的不是"沉积有用"，是**"近重复任务的计划回放有用"**——这是 L1 情景通道的窄用例（真实世界对应：重复相似工单），不是 L2 机制规则的证据，两教义（P5a.17/24）不因此动摇。
3. **安慰剂带（必须引入的先验）**：e3-e5 的邻接注入实质是安慰剂注入（无关内容），其同轮臂差读数 +4.2/+11.5/+2.6pp（受 Thompson 分配污染，仅作量级参考）。**e7 的 +15.7pp 必须相对这条 0-11pp 的安慰剂带判读，而不是相对零。** "注入任何计划状文本"本身可能有效（引导谨慎行为/更长思考）。
4. **watchlist 一致性**：三隔离案（A-008/A-019/R-105）e7 仍 FAIL 且多为 harness/任务缺陷所致——与既有判决一致，无新信息。A-027/A-026/R-102 掉落（多为 direct 臂）登记为噪声观察，不行动。
5. **结论**："注意力方法有用"不予确认，也不否定。状态=**疑似有效、污染未排、等纯化复现**。L1 通道维持 P5a.17 原判（证据层，非注入资产）。

## 二、四个选项的法定顺序

用户提出：①跑 epoch-8 ②DeepSeek 读 a23-25 先下结论 ③按 e7 调 a23-25 ④人工核准数据。

**裁决：④+机制审计（零 token）→ ③（仅小修 a23）→ ①（改设计后的 e8，非原样复制）；②可以做但只是参考，不构成结论，且不阻塞主线。**

理由逐一：

- **反对原样复制 e7**：MR-1 纪律——花 10M tokens 复现一个已知有两条泄漏通道的读数，得到的是第二个受污染数字。统计复现（告警1）与机制纯化（告警2/3）必须合并进同一次运行，一次回答两个问题。
- **④先行**：泄漏图谱不全之前，e8 的最终配置定不下来（若人工核准发现 sibling 通过=抄答案值，e8 的注入物必须加脱标识处理，而不只是排除 self）。19 个案例、一个晚上，换 e8 的设计确定性——全链路最高 ROI。
- **③小修**：e7 不触及 a24/a25（它们管 L2 资产与迁移，e7 测的是 L1 通道）；a23 需增补一条原则（见 §三），这是教义该有的自我更新，不是返工。
- **②的定位**：DeepSeek/opencode 读 a23-25 做**代码级可行性审查与漏洞反驳**——它在这个角色上历史表现好（Thompson 取证、迁移分析纠错）。但被测对象与执行器没有对教义的裁决权，其输出进入证据链，不进入结论。

## 三、P5a.23 增补条款（即时生效）

**L1 同轮双臂设计增补：当处理=内容注入时，因果归因必须过泄漏控制清单——**

1. 注入物不得含本任务自身的任何历史产物（self 排除）；
2. 注入物不得含答案值（具体航班号/用户ID/数值），只允许结构与动作模式（脱标识检查，F1  lint 的逆向应用）；
3. 判读阈值相对**安慰剂带**而非零——有条件时设安慰剂臂（注入异族/无关计划文本）；
4. 注入集中度作为调节变量记录（单一注入物被复用次数）。

原 L1-L5 阶梯其余不变。
