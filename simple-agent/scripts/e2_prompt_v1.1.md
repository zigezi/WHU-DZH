# E2 提示词模板 v1.1（冻结 · P5a.89 §一 + P5a.91 §一）

## 模板（统一，lint 对象）

> 请对文件《{文档代号}》执行【{任务型名称}】。依据随附的核查清单逐项核对，输出逐项结论
> （通过 / 不通过 / 不适用）及证据（**原文片段 quote（≤50 字）+ 章节路径**；不用行号）。

纪律：
1. **证据形式 = 原文片段 + 章节路径**（a91 §一.1；行号因抽取工具而异，废除）。
2. **核查清单 = 纯陈述句**（"申请书第三部分与实施方案第五部分数值等同"✓；"请比对预算""注意单位换算"✗）。
3. **任务型名称严格映射，零修饰词**。
4. 核查清单是**任务规格（查什么）**，不是方法（怎么查）——不构成外源结构注入。
5. **零方法建议**：禁"建议编写脚本""注意单位换算"等任何注入性措辞。

## 评测器侧纪律（a91 §三）
- 结构化参数通道：阈值以 JSON 字段下发（如 `{"credit_report_validity_months": 3}`），评测器**不解析自然语言段落**。
- 白名单读取 + 静默丢弃：只读规定字段，未知字段忽略，不得 Schema 崩溃/判死。
- Env_Missing_NA：因环境缺失（如 R3.5 榜单通知缺席）触发的 NA，尸体台账标"环境缺失合法 NA"，不计操作者能力缺陷。
