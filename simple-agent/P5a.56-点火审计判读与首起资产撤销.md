# P5a.56 — 点火审计判读：首起资产撤销与谓词两型立法

> 触发：追溯点火审计（962 run 静态回放）结果——总救场 8；硬线违例 lock_order_v1（118）、certificate_update_v1（1）；零覆盖四件。
> 裁决：**certificate_update_v1 撤销（首起资产撤销）；审计判据按干预语义分级细化；谓词两型（观测依赖/前置强制）立法；采收季收官批准。**

## 一、总评

审计仪器按设计意图工作：抓住 1 个真缺陷 + 1 个判据缺陷 + 1 个系统性盲区。**历史 ROI 下界 = 8/962**（lock_order 6 + items_count 1 + non_delivered 1）——免疫系统第一个真实数字：若历史重演，八个资产改写八具尸体的结局，代价是约 12% 的 run 付一步良性否决税。安全带经济学：每次佩戴成本一步，每次撞车价值一整条 run。

## 二、三案裁决

**案 1：certificate_update_v1 → 撤销（revoked），不是回炉。**

- 定性：它的误伤是**行为改道型**——否决合法改签并强推换支付，这是真实伤害，不是良性再发；
- 回炉不可能的硬理由：窄化所需的"本次改签是否需费用"在 args 里不可观测（与 gift_card 同一覆盖缺口）。**点火必要条件不可观测的谓词，没有窄化余地，只有撤销。**
- 登记为**系统首起资产撤销**：B-3 status=revoked，死因知识转入负先例册（L1.5 警告通道保留）。
- **新出生要件立法（可观测性证明）**：自本裁决起，桌面审查必须证明谓词点火条件可由 args/可观测状态确定性计算——不可证明者不予出生。此条追溯解释了 gift_card_balance 的覆盖缺口为何只能登记不能修复。

**案 2：lock_order_v1 的 118 次 → 接受良性再发重分类，三条但书。**

1. **税负登记**：118/962 ≈ 12.3% 的 run 为每个首改付一步否决税——成本模型入册，不许只记收益不记税；
2. **电池补案**：金丝雀阴性对照当年只测了"已改地址→不撞"，漏了"本任务无需改地址"这一真实合法形状——补上（审计的存在意义正是抓这种漏）；
3. **结局保持性静态不可证**：历史轨迹里没有拦截器，agent 被否决后的反应只能由金丝雀推断——静态审计只能判"点火是否如设计"，结局问题留给在役干预日志做最终确认。

**案 3：判据细化立法（干预语义分级）。**

- **良性再发型**（veto-then-reissue，合成文案自带"重新发起即通过"）：点火 PASS run ≠ 误伤；判据 = 是否改变结局 + 税负登记；
- **行为改道型**（否决并改变 agent 后续动作方向）：点火 PASS run = 硬线违例，零容忍。
- 复跑审计后升级名单：**items_count_match_v1、non_delivered_exchange_v1（覆盖 0.50 注记）、lock_order_v1（良性税 12.3% 注记）→ field_validated(static)**；零覆盖三件套与 repeat_failure_v1 维持 T1_candidate，盲区入册（repeat_failure 历史救场 0：部署依据是金丝雀而非历史死因匹配，如实标注）。

## 三、系统性发现（本次审计最大产出）：谓词两型立法

零覆盖四件的共同机理：**死因 run 里的 agent 从未产生谓词所需的观测信号**（没查座位/余额/total），谓词保守不点火——它们保护的是"查了还乱来"的少数谨慎型死亡，拦不住"根本不查"的多数盲动型死亡。

立法登记谓词两型：

- **观测依赖型**：需要先验观测才能判定——盲区天生，价值有限但误伤零；
- **前置强制型**（lock_order 式）：未观测即否决 + 良性再发——用普适的一步税换多数盲动型死亡。

**授权（非命令）**：将 flight_availability_v1 改造为前置强制型试产原型（book/update 前无本 run 可用性观测 → 否决"先查座位，查完重发即通过"），走全路径：规格 → 桌面审查 → 电池（含"已查座→不撞"阴性对照）→ C-1 → 审计复跑。原型审计结果出来之前，payment_sum / gift_card 不跟进。

25 候选全部处置完毕、无新增；verdict_fail 173 条不开采（能力/歧义型，拦不出能力）。**τ 采收季正式收官，转哨兵模式**：7 资产在岗（1 撤销）、干预日志自然累积、backlog 仪器两件已落地。

## 五、一句话

**审计的价值不在它批准的，在它抓住的：一个真缺陷被撤销、一个判据缺陷被细化、一个系统盲区被命名。八哨兵剩七——但从此每个都知道自己拦什么、拦不到什么、拦错了会怎样。**
