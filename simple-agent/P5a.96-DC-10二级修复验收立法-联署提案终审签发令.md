## 一、条款一（视觉审计，R1 兜底）——采纳 + A1 钉界

提案内容与本朝立法谱系相容（a83 文本先行冻结、a91 不可判→NA、QB-4 坐标陷阱），其反假尸体意图正确。但"审计动作：核对 PDF 原件签署页"必须钉死执行主体与语义，否则等于给 epoch-1/2 开后门。

**A1 修正案（钉界）：**
1. **视觉审计是人工动作**（复检人=用户或其指定人），epoch-1/2 **不为它建任何仪器**——a83 冻结不因本条款开口。
2. R1 签署项拆分为二：**(i) 印章/手写签名的物理存在性**——永久 NA（文本不可判），入 documented exclusion，不触发、不计缺陷；**(ii) 签署字段的文本标签存在性**——照常判定（文本层可见的形式缺陷是真缺陷）。
3. "R1 规则降级"语义钉为 **NA（文本不可判）**，沿用 Env_Missing_NA 标记法，永计为零能力缺陷；视觉审计产出仅入 tier=audit 台账，**永不入基线、永不入 fixture、永不改 deid 副本**（提案自带此禁，重申确认）。

## 二、条款二（白名单硬护栏）——采纳 + A2

优先级铁律（**实体匹配 > 白名单阻断**；白名单只过滤候选、不拦截实体；已确认 PII 实体可击穿其组成词的白名单保护——"北京己任"击穿"北京"）**是对 a95 §四.1 的有效补丁**：没有击穿条款，白名单会以拦截实现，造出新的召回洞（含通用词的实体被整词放过）。提案把洞补上，记功。

**A2 修正案：** SAFE_WHITELIST 与任务荷载保全名单属**评测配置**，并入 taskbook_fingerprint 钉指纹；名单的任何增删走变更控制（版本 + changelog + 重钉 + 双签），不得在修复过程中静默扩编。

## 三、条款三（变体闭包探针）——采纳 + A3（本令最重的一处）

实体锚点纪律（变体只从映射表实体生成：[短名 / 断行折叠 / 胶合粘连 / 专属形近字]，禁止脱离实体字典的全局形近扫描）采纳——它防的是探针侧假阳性（"已经"误报为"己任"漏遮），方向正确。诚实披露义务采纳，与 a95 §四.6 合并为常设条款。

**A3 修正案（防高空真，必须钉）：**
**闭包探针的量程是"已入表实体的变体残留"，它结构性管不了"未入表实体的发现"。** DC-10 首轮的徐康恰恰是**从未入表**——若验收只看闭包探针，下轮回执将交出一份"闭包残留 0"而徐康继续裸奔的**高空真**，与 a92 §2.1 的空真同构、高一级形态。故验收定义钉为**两层双绿**：

- **第一层（发现召回）**：召回 fixture（合成埋件，a92 §4.2 + a95 §四.2 扩展形态）100% 遮蔽 + 人工锚复检——管"该入表的都入表"；
- **第二层（变体闭包）**：本条款探针全量扫描，命中即漏遮——管"入了表的一字不漏"。

探针报告的覆盖域声明必须写成："**闭包残留 0（量程：已入表实体之变体；未入表实体不在本探针量程，由 fixture 与人工锚覆盖）**"。少一句，回执退回。
