# P5a.52 — 设计变更授权：v3 真实仓库+变异注入，与校准封顶条款

> 触发：e3-pilot-stage1-v21.md——静默 bug 两轮仍 0.0%，P5a.51 预注册路径用尽，opencode 停跑上报，请求承认设计变更或改判收官。
> 裁决：**承认设计变更，授权 v3 = 真实仓库 + 变异注入（dogfooding）；同时立法校准封顶条款，防追难度跑步机。选项 2（先导收官）驳回。**

## 一、验收与判读

- 三轮校准记录完整：v1 单发合成 0.0% / v2 可见照出 0.0% / v2.1 静默边界 0.0%（n=9+5）；token 累计 8,419 = **预算的 1.05%**。三次停跑全部按纪律，未擅扩——校准程序本身已成为系统最可靠的部件。
- 判读确认：单函数形态对 DeepSeek V4.1 全饱和。机理一句话——**过程性死亡需要过程**：单函数可被模型整体装入工作记忆，无搜索、无状态、无多步交互，故无过程可死。前沿带（20–70%）只存在于模型必须**搜索**（定位）与**维护跨步状态**（改一处顾全模块）的尺度。
- 旁证采纳：标量单函数装配不出 2 个独立静默 bug（rejected 4）——形态容量到头，不是旋钮没拧够。

## 二、v3 设计变更（授权正文）

**形态**：真实多文件模块 + 变异注入。任务 = 真实模块的变异态（注入 bug）+ 测试套件；agent 读→跑→定位→修→复跑；隐藏/补充边界测试判分。

**模块来源（dogfooding 立法）**：优先用**本项目仓库自身**（simple-agent 的多文件 Python 模块），可选补 1–2 个小型开源库。理由四条：

1. **防污染免费**：变异注入态定义上不存在于任何训练语料——比自构造题更强的保证（自构造题还可能撞题型，变异态连"题"都不存在过）；
2. **真实复杂度免费**：多文件、跨函数依赖、真实数据流——不用造多文件生成器（那才是贵的方案）;
3. **装配门不变**：注入 bug 必须杀 ≥1 条测试（库测试薄就先补边界测试——**顺手强化自家测试套件，算这笔支出的正外部性**）；参考态全过；
4. **簇单位**：文件/模块为 family。

**安全条款（不可协商）**：任务上下文永不包含 `.env`/密钥/映射表；任务切片只取纯逻辑模块（生成器、谓词、装配器优先，避开 I/O 与配置层）。

**金丝雀变更登记**：公开题金丝雀在单函数形态已证无读数（两轮 0），v3 起暂停；防污染职责移交"变异新颖性"承担，记入仪器校准注记。

## 三、校准封顶条款（防跑步机，本条是本次裁决的另一半）

1. v3 阶段一探针 10 题，冒烟先行照旧，预注册唯一调整路径：失败率 >70% → 缩模块（减文件/减函数）或放回一条边界测试；仍 0.0% → 跨文件注入第 2 个交互 bug。记录、锁死。
2. **若 v3 用尽调整仍出带，停止追难度。** 届时结论登记为事实："廉价自构造/变异基板够不到该模型的能力前沿，代码域免疫工作须 SWE-bench 级基板"——带着这个事实重新开裁，而不是再发明 v4。校准最多再上一级，这是封顶。
3. 预算硬顶 0.8M 不变（已耗 1.05%）；v3 建造零 token（装配层 + 变异算子复用）。
