## §一 总评

三型方向**全部采纳**，双向审查流程有效（Qwen 在任务 2/3 上的判断获本席背书，记二审档案正面积分）。但有**一处红线级过界**（§三）、**一处过 claim**（§二）、**一处术语钉界**（§六），修正后方可入任务书成书。

## §二 任务 1（合规检查）：采纳，修正过 claim

**采纳**：python-docx + 正则建立结构金标准，不耗 token；评测器版本（含 python-docx 等解析库版本号）入 env_fingerprint——此绑定本就为 a80 所要求，用户强调正确，并扩展钉死：**评测器是仪器的一部分，评测器版本与规则集版本同样入指纹**，评测器升级 = 仪器漂移，须重过缺陷注入夹具标定。

**修正「必然锁定」**：「Agent 失败的原因必然被锁定在上下文窗口管理或工具调用幻觉上」——过 claim。确定性金标准保证的是**失败检测**的确定性（agent 答案 vs 金标准，判死无误），不是**死因归因**的确定性。死因可能是上下文管理、工具幻觉，也可能是提前放弃、预算耗尽、误读任务书——归因必须走过程轨迹（钩子记录），不许先验锁定。先验锁定死因 = 我们批过的「捏造尸体」的另一副面孔。

**钉界 oracle 与 operator**：金标准管线是裁判，不约束被试。Agent 若选择自建 python-docx 检查脚本而非用 LLM 肉眼比对——**这是合法成功路径，甚至是优等路径**，其死亡（脚本写错）同样是合法尸体。RQ1 测的是操作者的真实行为分布，路径自由是基线成立的前提。

**钉界 smoke**：「冒烟测试不需要 LLM 介入」仅适用于金标准基线建立；smoke 先导（a81 §六.2）的本职是标定 **agent 跑题**的单题成本，必须真跑 agent。

## §三 任务 2（数字一致性）：采纳，红线级修正

**采纳**：金标准管线强制工具化（确定性抽取 + 代码执行比对），正确。数字/金额是最可规则化的域，**抽取优先纯正则 + 单位归一表**（100万 / 1,000,000 / 壹佰万元 / ￥100万）；「小模型抽取」降级为备选——仅当规则方案在缺陷注入夹具上拿出「不足」证据后方可引入，且引入即入指纹。单位归一表是金标准管线最可能的藏虫处，夹具标定重点照顾。

**红线级修正**：「在 E2 的流水线上，绝对不能让 LLM 直接用自然语言判断」——此禁令**只对金标准/评测器侧成立，绝对不得延伸约束被试 agent**。若强制操作者使用工具化架构，即外源结构注入，e8 刚证伪过它，a81 §RQ1 明令 epoch-1 零干预。被试用肉眼比数字然后死于单位幻觉——**这正是 RQ1 花钱要买的真实数据**。裁判强制确定性，被试保持自由，两者混淆 = 基线污染。

**死因登记**：Tool_Calling_Failure / Extraction_Hallucination / Math_Logic_Error 三候选类登记入 e2_corpses schema 候选册，纪律同 a82 signal_death——**首个真实实例入账后方计入死亡类别多样性**，防 class 刷触发线。归因证据要求：Extraction_Hallucination 的判定必须有金标准抽取结果与 agent 声称数字的比对记录在卷。

## §四 任务 3（全文审查 → 维度合规审查（规则化））：采纳，连带升级

**采纳**：废弃「检查风险与承诺是否矛盾」式模糊指令，改写为集合逻辑（A 集合出现 ∧ B 集合缺失 → 判死）；**改名「维度合规审查（规则化）」**，剥离主观裁判属性——命名即契约，符合 naming_proof 家风。

**规则集纪律**：关键词集合是领域知识，必须 (i) 随任务书成书**预注册冻结**；(ii) 版本钉死入指纹；(iii) 过缺陷注入夹具标定灵敏度/特异度，证据入卷。规则集漂移 = 仪器漂移。

**连带升级——评测器形态变更**：三型全部规则化后，epoch-1 评测器由 a83 §五.3 的「(a)+(b) 混合」**升级为纯 (a) 确定性评测**。收益：零评审偏差、零评审 token、ITT 分母完全干净。(b) LLM 评审 + rubric 降为 epoch-2+ standby，若届时引入语义型任务再激活。**人工抽检锚保留**（P5a.35 模式，抽样核对确定性裁判本身的判定）——LR-1 在案：已知答案夹具也会错，规则集由人编写，错的可能不是模型而是尺子。

## §五 语料来源：验收

政府网站招标文件的盲评纯文字版——**验收通过**：

1. 公共来源，且出版方已做盲评匿名化，脱敏负担大幅减轻；**扫描义务不免**——盲评≠零残留，入库前仍过一遍残留标识符检查（公司名/人名/编号）。
2. 纯文字版与 P5a.83 文本先行范围冻结完全一致；pdf 抽取失败死因类登记休眠（非必需类，不影响多样性判据）。
3. 盲评文本自带「格式刚性」属性（盲评有严格版式规范），恰好喂任务 1/3。
