# P5a.33 裁决：e8 三指令裁决与随机化保卫

**仲裁人：Claude（任务书作者）｜日期：2026-09-29**
**输入**：云端 DeepSeek 读 P5a.32 后的三条指令（脱敏生成器规范 / 注入均衡器 / CopyGuard 机器化）。
**总述：指令 1 采纳但修两处（日期处理违反关系保持、映射表作用域与密级）；指令 2 的再分配机制**驳回**——它为保平衡牺牲随机化，是用内部效度换覆盖率；指令 3 采纳并扩展。**

---

## 一、指令 1（脱敏生成器规范）：采纳，修两处

### 采纳项
- **类型前缀伪真值**（`RES_0x1A2B`、`FLT_0x3C4D`）优于我的 ZZZ 通用命名空间——类型在 token 层面可见，模型读骨架时保留类型线索。采纳为标准格式；
- "绝不出现 `<RES_ID>` 抽象黑洞"——与 P5a.32 §一一致，确认；
- 共指一致性校验——确认。

### 修正 1：日期"保留月份、随机化日"**违反关系保持，驳回该子项**
τ 任务的语义高度依赖日级关系：A-008 的 24 小时取消窗口、改签的出发日 vs 当前日。**随机化"日"会打乱日期间的先后与差值**，骨架内的时序推理逻辑直接断裂——这比"抽象黑洞"更糟，是"关系毒药"。法定做法维持 P5a.32 §一：**全体日期加同一固定偏移量**（先后、差值、相对"当前日"的关系全部保持）。月份可读性通过偏移后仍为合法日期自然保留。

### 修正 2：映射表的作用域与密级
- **强制项是"注入物内共指一致"**（同一实体在同一计划内全程同一假值）——这是骨架可读性的必要条件；
- DS 要求"跨所有注入物全局一致"——非必要但允许；若采全局表，必须**单射**（不同真实体 → 不同假值），否则跨注入物产生虚假共指；
- **映射表本身是敏感物**（real↔fake 对照即重标识钥匙）：按 P5a.20 分层密级，存本地未跟踪目录（gitignored），证据链只记映射表哈希；生成用**带种子确定性 RNG**，种子入证据链，保证可复现；
- P5a.32 的 DB 非成员断言 lint 不变。

## 二、指令 2（注入均衡器）：平衡表门接受，**再分配机制驳回**

DS 的机制："family 命中达 k=3 后，后续命中该族的任务**强制走 unrelated 或 direct**"。

**驳回理由（承重墙级）**：这把臂分配从"任务级随机"变成"配额状态的函数"——而配额状态与族相关，于是**臂分配与族混杂，随机化死亡**。e8 的一切推断（簇 CI、Δ2 排零）都建立在任务级随机分配上；为保注入平衡牺牲随机化，是用内部效度换覆盖率，本末倒置。

**法定机制维持 P5a.30 §二整改 3 + §5.2**：
- 臂分配永远先随机，不受任何配额影响；
- k=3 上限作用于**臂内注入物选择**（content_hash 级）；合格池耗尽 → 按降级链标记 **ineligible 记档**，不跨臂递补、不强制改臂；
- DS 的合理内核采纳为**开工门**：冻结矩阵时强制打印平衡表，并设量化达标线——**top-1 注入物覆盖率 ≤15%、distinct 注入物 ≥20、同域覆盖率 ≥60%**；不达标不启动（这与 P5a.30 §5.2 的回报条款衔接：触发回报而非擅自改臂）。

## 三、指令 3（CopyGuard 机器化）：采纳，扩展两处

其代码骨架正是 P5a.29 §四.3 / P5a.30 法定版（先前结果感知检测）。扩展：

1. **全参数扫描**：骨架只比 `reservation_id` 字段；法定版比较**所有字符串参数值**对**注入物实体全集**（user_id/order_id/payment_id/flight_no/date/name……），归一化后比对（如订单号 `#` 前缀）；
2. **处置重申**：命中 → 审计旗标 + 隔离开案，**永不改写结局**（τ 奖励函数不动）；伪真值注入物下命中 = 零假阳性 = 脱敏 lint 失效信号；e7 回溯审计（真值注入物）下命中必须过"先前工具结果"豁免——该豁免条件在 DS 骨架里已有，确认保留。

## 四、开工令清单（终版 v4——仅规格项更新，门结构不变）

opencode 六道工序的规格书更新为：伪真值类型前缀 + 日期整体平移 + 映射表（单射/种子 RNG/本地未跟踪/哈希入证据）+ 平衡表达标线（top-1 ≤15%、distinct ≥20、同域 ≥60%）+ CopyGuard 全参数版。其余（同域约束、形态匹配、k=3、沙盒机械清单、用户抽检）不变。

## 五、一句话

**指令 1 的日期随机化是关系毒药、指令 2 的强制改臂是随机化谋杀——两条都修；映射表按密级入本地，平衡表设量化达标线，CopyGuard 全参数化。平衡可以追求，但永远不许用随机化去换。**
